How to download extracted parts with your manager of choice
Step 1

Click Copy URLs above. In FDM, click the Main Menu (three lines ).

Step 2

Click Paste urls from clipboard in the menu to add all parts automatically.

JDownloader 2 Quick Setup:

  1. Click Copy URLs above. JDownloader 2's LinkGrabber will capture clipboard URLs instantly.
  2. Alternatively, click Save links.txt, then in JDownloader 2 navigate to File -> Add Links -> Load Text File.
  3. Click Start All Downloads in JDownloader 2 to begin simultaneous multithreaded downloads.

Internet Download Manager (IDM) Setup:

  1. Click Copy URLs above. Open IDM and select Tasks -> Add batch download from clipboard.
  2. Or click Save links.txt, then in IDM go to File -> Import -> From text file.
  3. Select all files and click OK to queue and start downloading all parts simultaneously.

aria2c / Command Line Setup:

  1. Click Save links.txt to download the URL list.
  2. Run aria2c in your terminal for ultra-fast multi-connection downloads:
    3. aria2c -i download_links.txt -j 4 -x 16 -k 1M
