How to Download extracted parts with your tool of choice
Step 1

Click Copy URLs above. In FDM, click the Main Menu (three lines ).

Step 2

Click Paste urls from clipboard in the menu to add all parts.

JDownloader 2 Setup:

  1. Click Copy URLs above. JDownloader 2 auto-grabs clipboard links instantly!
  2. Or click Save links.txt, then in JDownloader 2 go to File -> Add Links -> Load Text File.
  3. Click Start All Downloads in JDownloader 2.

Internet Download Manager (IDM) Setup:

  1. Click Copy URLs above. Open IDM and select Tasks -> Add batch download from clipboard.
  2. Or click Save links.txt, then in IDM go to File -> Import -> From text file.
  3. Select all files and click OK to start downloading all parts simultaneously.

aria2c / Command Line Setup:

  1. Click Save links.txt to save the file.
  2. Run aria2c in your terminal for ultra-fast multi-threaded downloads:
    3. aria2c -i download_links.txt -j 4 -x 16
